# 🚤 ボートレースAI予想アプリ

当日の全国のボートレース出走表・直前情報・結果をWEBから自動取得し、統計モデルで各レースの予想(予想印・勝率・推奨買い目)を表示するアプリです。

## 公開URL(スマホ・外出先からアクセス可)

**https://baka0910.github.io/boatrace-predictor/**

GitHub Pages で公開しています(リポジトリ: https://github.com/baka0910/boatrace-predictor)。スマホのブラウザでこのURLを開けばどこからでも使えます。ホーム画面に追加するとアプリのように起動できます。

アクセス時に**暗証番号**の入力が必要です(簡易PINロック。一度解除すればその端末では次回から不要)。コードには暗証番号のハッシュのみ埋め込んでおり、検索エンジンにも載らない設定(noindex + robots.txt)にしていますが、暗号学的に厳密な認証ではないため機密情報は置かないこと。

## 主な機能

- **レース一覧**: 各レースに「おすすめ度(★1〜5)」と本命(◎)を表示。★は本命の推定勝率と2番手との差から算出した予想の自信度
- **レース詳細**: 予想印・推定勝率・推奨買い目・信頼度。確定後は結果と収支も表示
- **📝 舟券データベース**: レース詳細の「🎫 買った舟券を記録」で、実際に購入した券種(3連単/3連複/2連単/2連複/拡連複/単勝/複勝)・買い目・金額を入力して記録。確定後は実際の払戻オッズから回収金額を自動計算し、DB画面で全体の回収率・回収金額・収支・的中率を表示。過去日の結果もアーカイブAPIから自動取得して答え合わせ。CSVダウンロード・JSONバックアップ/復元に対応(データは端末のlocalStorageに永続保存)
- **📊 回収率**: 本日の確定済み全レースを推奨買い目で買った場合のシミュレーション

### 公開サイトの更新方法

`public/` 内のファイルを変更したら、以下でサイトに反映されます。

```bash
cd boatrace-predictor
git add -A && git commit -m "変更内容"
git push                                        # main を更新
git subtree push --prefix public origin gh-pages  # 公開サイトを更新
```

## 起動方法

```bash
node boatrace-predictor/server.js
# → http://localhost:3300 をブラウザで開く
```

依存パッケージ不要(Node.js 10以上で動作)。

サーバーを起動しなくても、`public/index.html` をブラウザで直接開くだけでも動作します(その場合はデータ元へ直接アクセスします)。「データ取得に失敗しました」と表示される場合はインターネット接続を確認し、「🔄 更新」を押してください。

## データ出典

[BoatraceOpenAPI](https://boatraceopenapi.github.io/)(ボートレース公式データを整形した無料API)から当日データを取得します。

- 出走表(選手勝率・級別・モーター/ボート2連率・平均STなど) … 5分キャッシュ
- 直前情報(展示タイム・展示ST・風・波・天候) … 1分キャッシュ
- レース結果(確定後に「答え合わせ」表示) … 1分キャッシュ

画面右上の「🔄 更新」でいつでも最新データを再取得できます。展示タイムはレース直前に発表されるため、締切前に更新すると予想精度が上がります。

## 予想モデル

勝率を **コース別基礎勝率 × 実力補正(乗算型)** で推定します。

- コース: 全国平均のコース別1着率(1コース55%〜6コース2%)に、場ごとのイン強弱補正(例: 大村=イン強、戸田=イン弱)を適用
- 実力: 全国勝率・当地勝率・2連率・級別(A1〜B2)・平均ST・モーター2連率・ボート2連率・F持ちペナルティ
- 直前: 展示タイム順位ボーナス(発表後)

推定勝率から予想印(◎○▲△✕)、信頼度(鉄板/本命/混戦)、推奨買い目(3連単本線・フォーメーション・抑え、2連単、3連複)を生成します。

## 回収率の検証(📊 回収率ボタン)

本日の確定済み全レースについて、「推奨買い目を1点100円(1レース11点=1,100円)で購入した場合」をシミュレーションし、以下を表示します。

- 全体の回収率・収支・総購入額・総払戻額・的中レース数
- 券種別(3連単/2連単/3連複)の的中率と回収率
- レース別明細(予想 vs 結果、的中した買い目と払戻金、収支)

払戻金はレース確定後にAPIから取得した実際のオッズ(100円あたり)を使用します。レース詳細画面の結果欄にも、そのレース単体の的中・収支が表示されます。
